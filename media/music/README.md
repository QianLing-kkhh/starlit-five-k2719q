# 背景音乐放置说明

请将有合法使用权的《偏爱》音频放在本目录，文件名使用以下任一种：

- `pian-ai.m4a`
- `pian-ai.mp3`

页面只会在用户点击纪念馆“进入纪念馆”或主剧场“拉开第一幕”等有效手势后，以较低音量播放。音乐由站点级单一音频实例承载，普通站内换展厅会继续当前播放位置；直接访问分馆不会自动播放。重要视频播放时会自动压低背景音乐，停止后恢复。音频加载失败时页面保持静默阅读，不影响正文。

真实音频文件由根目录 `.gitignore` 排除，不进入 GitHub。当前本地文件来自用户提供的 `BV1S5411w7WH.aac`，按原字节复制为 `pian-ai.m4a`；本地可播放不等于获得公开发布使用权，发布前仍需单独确认授权。
